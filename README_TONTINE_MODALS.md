## 🎯 Comment utiliser

### Aller à la page tontine:
```
Menu → Finance → Tontines
OU
http://localhost:3000/tontines
```

### Tester les modales:
```
1. Cliquer sur "Détails" d'une tontine
2. Modal s'ouvre
3. Cliquer "Fermer"
4. Cliquer sur "Membres"
5. Modal s'ouvre
6. Fermer
```

### Tester le dark theme:
```
Si vous avez un switcheur de thème:
Settings → Theme → Dark
Voir les couleurs changer!
```
